## 2. 🚨 WebContainer 는 쓰지 않는다 (2026-08-15 방향 전환)

당초 실행 엔진은 WebContainer(브라우저 안 진짜 Node 런타임)로 확정돼 있었다. **조사 결과 철회한다.**

### 조사 결과 (근거)
- **상업 라이선스가 필요하다.** 공식 문서: *"Licensing is required for production usage of the API in a commercial, for-profit setting."* 교육기관 할인·비영리 예외 조항은 약관·엔터프라이즈·FAQ 어디에도 **없다**.
- 🔴 **가격표가 공개돼 있지 않다.** 세 곳 모두 「연락 주세요」로 끝난다.
- 🚨 **공짜 한도가 문서마다 다르다** — 이용약관은 「월 500 세션」, 공식 FAQ는 「월 10,000 요청」. **단위가 달라서 우리가 한도 안인지 밖인지 계산이 불가능하다.**
- npm 패키지(`@webcontainer/api`)는 MIT 지만 **실제로 돌려면 StackBlitz 서버에 접속해야 한다**(공식 표현: hosted proxies and server-side acceleration). 자체 호스팅은 엔터프라이즈 계약에서만.
- 약관 위반 시 *"access may be revoked"* — 우리한테는 **수업 중에 실습실이 안 열린다**는 뜻이다.

출처: `webcontainers.io/enterprise` · `stackblitz.com/terms-of-service` · `developer.stackblitz.com/guides/user-guide/general-faqs`

### 대신 무엇을 하나 — 우리가 만든 「수업용 셸」
학생이 `ls`·`cat`·`npm test` 를 치면 **우리가 가진 스냅샷 파일의 실제 내용**과 **결정적 검사기의 실제 판정**을 보여준다.
학생에게 **축소판임을 명시적으로 고지한다**(jery: 「당연히 가짜임을 알려줘야지」).

🔑 **12강에서 「가짜」가 되는 것은 셸 그 자체 하나뿐이다.** 파일도 진짜, 판정도 진짜, AI 호출도 진짜다.

| 학생이 겪는 것 | WebContainer 면 | 우리가 만들면 |
|---|---|---|
| `ls`·`cat` | 진짜 파일 | **진짜 파일**(스냅샷을 실제로 갖고 있음) |
| 3번 다른 결과 | 사전 제작 | **사전 제작**(원래 설계부터 AI 0회) |
| AI 호출 | Claude | **Claude**(`/api/vibe/my-turn` 재사용) |
| `npm test` | 브라우저 실행 | **서버·클라이언트의 결정적 검사기** |

### 이걸로 사라진 문제들
라이선스·비용 · 수업 중 외부 서버 의존 · 태블릿 폭 문제 · COOP/COEP 헤더 · 부팅 대기.

🚨 **되살리지 말 것.** 다시 WebContainer 를 검토할 이유가 생긴다면 그건 **19강(학생이 테스트를 직접 작성해 실행)과 22강(진짜 git 훅이 진짜로 막는다)** 때문이지 12강 때문이 아니다.
🔑 그래서 **명령 실행부를 함수 하나로 격리해 짓는다**(§5 골격 1) — 그날 화면을 다시 짜지 않아도 되게.

## 3. ✅ 확정된 결정 3건 (2026-08-15 jery 「셋다 추천대로 진행해」)

### 가) 수업의 주장 = 「같아진다」 → **「약속을 지킨다」**
🚨 원래 설계의 6단계 「다시 3번 돌리면 **같아진다**」는 **성립하지 않는다.** 진짜 AI 는 규칙을 줘도 글자가 똑같아지지 않는다.
→ 초록을 띄우려면 그 장면을 **녹화해야** 하고, 그러면 「AI 호출은 진짜」라는 약속이 안에서 깨진다.
→ 게다가 AI 호출 산수가 안 맞았다: 5단계 1회 + 6단계 3회 = **4회**인데 상한은 3회.

**바꾼 안**: 세 결과를 **받아서 처리하는 프로그램(파서)에 넣는다.** 2개에서 터진다.
```
✓ run-1  할인율 10%
✗ run-2  터짐: "10% off" 에서 숫자를 못 찾음
✗ run-3  터짐: "0.1" 은 10%인가 0.1%인가
```
규칙을 쓴 뒤에는 셋 다 통과 — **글자가 같아서가 아니라 형식을 지켜서.**

한 번에 다섯이 풀린다: 거짓 명제 소멸 · 호출 산수 정상(재생 3[라벨] + 초안 1 + 검증 2 = **실제 3회**) · 채점이 결정적 코드가 되어 **LLM 판정기 삭제**(프롬프트 인젝션 소멸) · 「AI는 원래 다르잖아요」 하는 학생에게도 놀라움 잔존 · 재생본에 `REPLAY` 라벨을 붙일 수 있어 고지 약속 유지.

### 나) AI 의 역할 = **「내 초안을 비평」**(A안)
학생이 **빈 편집기에 손으로 먼저 쓴다** → `claude review` 로 「어디가 애매한지」를 받는다 → 고친다.
🚨 **B안(AI가 초안 생성)을 안 고른 이유**: 다듬지 않고 내도 통과할 수 있어 「규칙을 쓸 줄 아는가」가 평가되지 않는다. 그리고 「AI에게 발주하기」는 **16강이 이미 담당**한다.
🔑 A안을 골라도 학생이 몰래 「써줘」 하는 걸 **완전히 막지는 못한다.** 달라지는 것은 **화면이 무엇을 권하는가**다 — 빈 문서와 `review` 가 먼저 보인다.

### 다) 💸 AI 월 지출 상한 = **$30**
Haiku 4.5 기준(입력 100만 $1 / 출력 100만 $5), 호출당 입력 약 2,000 · 출력 약 500 토큰 가정:

| 범위 | 비용 |
|---|---|
| 학생 1명(AI 3회) | **$0.014** |
| 한 반 30명 · 12강 1회 | **$0.4** |
| 6강 전체 × 한 반 | $2.5 |
| 6강 전체 × 3개 반(최대) | **$7.6** |

**정상 사용은 돈이 거의 안 든다.** 상한은 정상 사용을 막으려는 게 아니라 **사고 시 손실을 끊으려는 것**이다.
🚨 이 화면은 **로그인이 없고**(수업 참여 코드만 있으면 들어옴), 참여 코드로 토큰을 다시 받으면 **1인 3회 제한이 우회된다.** 밖에서 두드리면 막을 게 없다.
→ $30 = 최대 사용량의 약 4배 여유. Render env 로 **무배포 조정** 가능하게 만든다(챗봇 `CHAT_MONTHLY_BUDGET_USD` 와 같은 방식).

## 5. 플랫폼 골격 6개

| 골격 | 내용 |
|---|---|
| **1. 셸은 순수 리듀서** | 🚨 `run(command) -> output` 은 **너무 좁다**(Codex). 파일 변경·현재 경로·호출 잔액·테스트 상태를 표현 못 한다. → `execute(command, state, idempotencyKey) -> {events, nextState}`. **이 한 함수가 훗날 진짜 런타임으로 갈아끼우는 자리다.** |
| **2. 미지원 명령은 정직하게** | 꾸며낸 대사 말고 **현재 상태에 맞는 오류 + `help`**. 지원 명령을 넉넉히: `help ls cat cd pwd clear npm test git status lab doctor edit claude review ask reset jump check exit` |
| **3. 채점 스파인** | 로컬 `npm test` = 피드백 전용. 점수는 **서버가 저장된 revision 을 숨은 계약 검사기로 재검증**. 🚨 **LLM 판정기 없음** — 결정적 코드만. |
| **4. AI 예산 다층** | 참여자·수업·전역 하드캡 + 입력/출력 토큰 상한 + idempotency key + 동시성 큐 + timeout. 전부 서버. **월 지출 상한 $30.** |
| **5. 체크포인트 격자** | `reset`=내 마지막 CP · `jump N`=모범이 내 것을 **덮지 않고 나란히** · `check`=서버 재검증. 점프 구간은 과정점수 0, 산출물 점수는 생존 |
| **6. 교사 관제** | 개인 카드 30장이 아니라 **「같은 데서 막힌 무리」 + 오류 상위 3**. 단, 🚨 **「N분째 진전 없음」은 단독 알림**으로 따로 뺀다 |

🚨 **한글 입력 위험도 정정(2026-08-15)**: 어제 「미검증이라 위험」이라고 쓴 것은 **과대평가였다.** 우리가 만드는 것은 xterm.js 가 아니라 **평범한 웹 입력창**이라 한글 위험은 0 이다. 진짜 걱정거리는 한글이 아니라 **태블릿에서 터미널 UI 를 90분 쓰는 것** — 그래서 골격 2(넉넉한 명령)·편집기 패널·스마트따옴표 정규화가 들어간다.

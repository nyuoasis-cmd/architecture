2) **산출물은 서버 저장** — 12규칙→13스킬→16AC→19약속 문장→22넘김 쪽지→23묶음 계보는 **참여자 토큰으로 서버에 저장**한다(진도 행과 같은 결). 기기가 바뀌어도 다음 차시에 이어진다. 별도 안내문·동의 절차는 두지 않는다(jery 확정 — 기존 챗봇·내 차례와 동일 결).
3) **준비 점검 화면** — 목차에 «0강»을 세우지 않는다. 수업 입장 직후 한 화면으로 브라우저·한글 입력·새 탭 열림·외부 링크 도달을 점검. 교사 리허설은 기존 시연 모드 + 노트의 «먼저 해 보기 5분» 섹션(SDD 결정 10의 체험 운영 섹션 안).
4) **짝 링크 공통** — 전부 새 탭으로 연다(iframe 차단 전제). 링크 레지스트리 한 곳에서 관리: 주기 응답 검사 · 대체 링크 · 학교망 차단 여부 · 앱 내 스냅샷 경로.

## 견학 키트 (견학형 12강의 표준 부품)

견학 링크마다 세트로 장착한다:
1) **관찰 미션 1개** — 답이 하나인 «찾아올 것»(예: 이 페이지의 ○○는 몇 개?). 일부는 robots.txt·404 페이지 같은 «숨은 방» 계열로. 답 입력 → 체크포인트 기록.
2) **교사 미리보기 캡처** — 노트에서 교사가 링크를 안 열고도 화면을 봄.
3) **앱 내 스냅샷 폴백** — 링크 사망·학교망 차단 시 스냅샷으로 자동 전환, 미션은 계속. GitHub 계열 링크가 차단되면 가짜 GitHub 화면이 폴백을 겸한다.

## 1. PR6 이 실제로 바꾼 것

### 조각 A · 「📋 교안」이 교사 세션 화면을 떠나 **학생과 같은 화면 안**으로

- 자리: 학습 화면 우측 콘텐츠 컬럼의 탭. `teacherPanel` 일 때만 생긴다(= 교사 미리 보기/시연 안에서만).
- 왜 옮겼나: DESIGN-POLICY §9.H-14 «교사 화면 = 학생 화면의 상위집합». 별도 사이드바를 두지 않아 폭이 안 늘어난다.
- **아코디언은 없앴다.** 예전에는 세션에 담긴 장을 전부 세워서, 전 장 세션이면 페이지가 24,000px 이 됐다.
  이제 **지금 보고 있는 그 장 하나**만 그린다 — «한 장일 때만 펼친다»는 규칙(`shouldExpandLessonPlanByDefault`)은
  규칙이 아니라 구조로 대체돼 삭제됐다.
- 「이 칸 문항을 연 학생 N/M」은 그대로 살아 있다. 🚨 다만 조회는 **교안 탭이 열려 있을 때만** 돈다 —
  교사가 수업 내내 띄워 두는 화면이라, 안 보는 탭 때문에 6초마다 조회가 나가면 그건 안 보이는 비용이다.
- 교사 세션 화면에는 «교안은 미리 보기의 📋 교안 탭에 있습니다» 한 줄을 남겼다(안 적으면 «없어졌다»로 읽는다).

### 조각 B · 🎬 시연작 — C형 → **B형**

- 입구: 교사 대시보드 「🎬 시연작」 → `/teacher/demo`
- 흐름: **매번 강 목록부터** → 「이 강으로 시연 시작」 → **새 시연 세션 생성** → 학생과 같은 학습 화면 + 시연 바
- 시연 바: 「🎬 시연 모드」 · 강·문항 · 참여 코드 · **📱 QR코드**(미준비면 `disabled`, 숨기지 않는다) · 「시연 끝내기」
- 학생은 그 QR/코드로 같은 자리에 들어와 옆에서 따라온다 → **B형 정의 충족**
- `shared/demo-screen-qr-inventory.md` 의 architecture 행 4곳을 갱신했다(§0 아키타입 · §1 인벤토리 · §1-B · Wave 2).

# 체험 명세 카드 — 23강 v1 (초안)

2026-08-17. 에픽 1 산출물 3/3. 정본 배정 = `MAP-experience-23lessons-v1.md`(v2), 원칙 = SDD 결정 1~22.
카드 형식: **부품 · 비유 · 체험 · 링크와 미션 · 산출물 · 본문 개편**. 견학형은 압축형.

공통 전제:
- 터미널형 강 = **전 문항** 체험 탭이 같은 실습실을 이어 씀(결정 21). 카드의 문항 미션은 방향 스케치 — 확정 대본은 구현 PR에서.
- 견학형 강 = 기존 견학(tour) 데이터가 출발점(이미 미션형: 배지·설명·steps·링크·«이 앱에서 해 보기»). 견학 키트 = 여기에 **고르기형 정답 체크 1개**(체크포인트)와 스냅샷 폴백을 더하는 일.
- 본문 개편 공통: 「내 차례」「챗봇」「실습 탭」 등 유령 탭 참조 제거 + 체험을 가리키는 문장으로 교체. 아래 «본문」 줄은 그 이상의 개편만 적음.

## 1강 (ch01) 컴퓨터가 1초 안에 하는 일 — 터미널형

- **비유**: 라면 끓이기(기존 본문 유지) — 재료(입력)·불(처리)·그릇(출력).
- **체험**: 첫 터미널 인사, 총 3분대. q1 `echo 안녕` — 친 것이 처리돼 나온다(입력→처리→출력 한 바퀴). q2 `date`·`cal` — 부품(시계)과 명령의 구분. q3 `apps` — 지금 «동시에 살아 있는 앱» 목록을 봄(정리자=OS). q4 `trace 클릭` — 클릭 한 번의 왕복 경로가 줄줄이 찍힘(REPLAY).
- **미션 수위**: 전부 «시키는 대로 한 줄 치기». 교정·해석은 로컬 1단 위주(AI 등장 최소 — AI 는 11강에서 처음 명명).
- **본문**: q1 라면 비유 유지, 각 문항 끝을 «터미널에서 확인해 보세요» 한 문장으로 체험과 연결.

## 3강 (ch03) 코드를 세상에 내보내는 길 — 유사 GitHub

- **비유**: **학교 게시판에 작품 걸기** — 교실에서 만든 것(내 컴퓨터)은 우리 반만 보고, 게시판(배포)에 걸어야 전교생이 본다.
- **체험**: 가짜 GitHub 대본 — 파일이 저장소에 올라감 → Pages 스위치 켬 → 배포 초록불 → «내 페이지 주소가 생겼다» → 새 탭으로 그 (가짜) 페이지를 봄.
- **링크·미션**: 견학 = GitHub Pages quickstart + **ai-school**(ai.teachermate.co.kr — 실제 GitHub Pages). 미션: «이 페이지 주소에 github 가 들어 있나요? (있다/없다)».
- **산출물**: 없음(구경·조작 체험). 도슨트 새 용어 = 저장소·배포 (2개).

## 5강 (ch05) 보이는 쪽과 안 보이는 쪽 — 터미널형 (X-ray)

- **비유**: **식당의 홀과 주방** — 손님이 보는 홀(화면)과 요리가 만들어지는 주방(서버). X-ray = 주방 창문.
- **체험**: q3(창구=API)이 축. `curl /급식.json` — 앱이 실제 렌더에 쓰는 JSON 1개(화이트리스트)를 받음 → 화면 요소와 JSON 값이 색으로 연결(«이 제목이 저 칸»). q1~q2 는 같은 화면을 «홀에서 본 것 / 주방에서 본 것»으로 비교하는 짧은 미션, q5~q7 은 견학 미션 유지.
- **미션 수위**: JSON 은 5줄 이하 발췌만. 새 용어 = API (1개).
- **본문**: q3 을 식당 비유 + X-ray 체험 중심으로 재작성.

## 8강 (ch08) 인터넷 너머의 보이지 않는 길 — 터미널형

- **비유**: **택배** — 주소(DNS)·포장(https)·가까운 물류창고(CDN).
- **체험**: q3 `lookup youtube.com` → 숫자 주소가 나옴(이름→번지). q2 `curl http://…` vs `curl https://…` → 한쪽은 «포장 안 된 상자» 경고. q4 `ping 서울` vs `ping 미국` → 숫자(ms)가 다름(가까운 창고). q6 실시간 메시지 데모(REPLAY). 응답 전부 사전 생성 + REPLAY 라벨.
- **미션 수위**: 결과에서 «어느 쪽이 빠른가요(서울/미국)» 고르기. 새 용어 = DNS (1개, https 는 q2 본문이 이미 다룸).
- **본문**: 택배 비유를 강 전체의 공통 실로.

## 11강 (ch11) AI에게 일을 시킨다는 것 — 터미널형

- **비유**: **전학생에게 부탁하기**(기존 12강 본문의 «AI는 언제나 새로 온 사람» 계승) — 매번 처음 보는 사람이라 매번 다르게 알아듣는다.
- **체험**: q1 `ask 학급 안내문 써 줘` 를 세 번 → 세 다른 답(진짜 호출, AI «필수»인 유일한 강 — 장애 시 대체 응답 풀). q3 흔들린 칸 세기 미션(고르기). q4 `ask` 뒤에 긴 대화 → «어디까지 기억하나» 실험. q5 시키는 사람이 알 것 고르기.
- **미션 수위**: 자유 입력은 q1 의 부탁 문장 하나뿐, 나머지는 고르기. 새 용어 = 0개(전부 우리말).
- **본문**: 12강(ch18) q1 과 겹치는 «세 번 부탁» 소재의 역할 분담 명시 — 11강 = 현상 체험, 12강 = 해결(규칙 문서).

## 12강 (ch18) 왜 하네스인가 · CLAUDE.md — 터미널형 (기존 실습실 확장)

- **비유**: **우리 반 규칙**(기존 본문 그대로 — 이 강이 쉬움 원칙의 원형).
- **체험**: 전 문항 확장 — q1 `ask` 세 번 결과를 runs/ 로 비교(미션 1~2). q2 명령만 있을 때 vs 규칙 파일이 있을 때 같은 부탁 비교. q3 `cat CLAUDE.md` 견본을 열어 네 칸 세기(고르기). q4 기존 미션 3~7(파서·차이 적기·규칙 쓰기·AI 비평·제출) 개통.
- **산출물**: **규칙 한 장** → 서버 저장(계보 1번).
- **본문**: 현행 q4 본문의 「내 차례에 넣고 보내세요」 등 유령 탭 안내를 터미널 미션 흐름으로 재작성(필수).

## 16강 (ch20) 기획 · 요구사항·이슈·AC — 유사 GitHub

- **비유**: **심부름 쪽지** — 「라면 사 와」만 적으면 엉뚱한 게 온다. 무엇을·몇 개·얼마 이하·안 되는 것까지 적은 쪽지가 완료 조건.
- **체험**: 가짜 GitHub 이슈 대본 — 심부름 쪽지 수준의 나쁜 이슈를 먼저 보고 → 내 완료 조건(대상·되면 성공·안 하는 것)을 이슈 양식에 채워 등록 → reviewer-bot 이 빠진 칸을 짚음 → 고쳐서 다시 등록.
- **링크·미션**: 견학 = github/docs 공개 Issues 목록. 미션 = «열린 이슈가 몇 개대인가요? (백 단위 고르기)» 수준.
- **산출물**: **완료 조건(AC) 한 벌** → 서버 저장(계보 3번). 새 용어 = 이슈 (1개 — AC 는 «완료 조건»으로만 표기).
- **본문**: 심부름 쪽지 비유로 재작성.

## 19강 (ch21) TDD 한 바퀴 — 터미널형

- **비유**: **받아쓰기 채점표를 먼저 만들기** — 채점표(약속 문장)를 먼저 쓰고, 그다음 받아쓰기를 시킨다.
- **체험**: q1 `check` — 채점표 없이 «다 됐어요»가 왜 못 미더운지. q2 약속 문장 견본 열어 보기. q3 약속 문장 먼저 쓰고 실행 → **빨강**(아직 없음) → 시키고 다시 실행 → **초록**. q4 내 약속 문장 작성·통과.
- **산출물**: **약속 문장 한 개** → 서버 저장(계보 4번). 새 용어 = 0개(테스트 대신 «약속 문장·채점표»).
- **본문**: 채점표 비유로 재작성.

## 22강 (ch22) 커밋·PR·보안 — 유사 GitHub

- **비유**: **학급 문집에 글 싣기**(확정 — 목업 2) — 쪽지 내기=Open · 선생님 검토=Review · 문집에 싣기=Merge.
- **체험**: q1~q2 넘김 쪽지(한 것·안 한 것·다음 사람에게)를 씀 → q3 «같이 넘어가면 안 되는 것» 문항에 **피싱 판별 미니 체험**(진짜/가짜 로그인 화면 6장 중 진짜 고르기, 오답은 반드시 해부 씬) → q4 가짜 GitHub PR 대본: 쪽지로 PR 열기 → 리뷰 코멘트 → 고침 → Merge.
- **링크·미션**: 견학 = github/docs 공개 merged PR 1건. 미션 = «이 PR 은 파일을 몇 개 바꿨나요? (고르기)».
- **산출물**: **넘김 쪽지 한 장** → 서버 저장(계보 5번). 새 용어 = PR·Merge (2개). 목업 2(experience-github-v1) 가 이 강의 확정 화면.
- **본문**: 문집 비유를 읽기 도입부에 심음(비유 다리의 출발점).

## 23강 (ch23) 종합 = 졸업 — 복합 (터미널 + 전시)

- **비유**: **졸업 전시회** — 한 학기 만든 것을 한 자리에 건다.
- **체험**: 터미널에서 `bundle` — 산출물 5종(규칙·스킬·완료 조건·약속 문장·넘김 쪽지)이 서버에서 불려와 묶임. 빠진 칸은 그 문항으로 돌아가는 문이 열림(q2 «빠진 칸 찾기»가 이 흐름). 완성 시 가짜 GitHub «내 저장소» 읽기 전용 전시가 열림(잠금 해제 연출) → 화면을 짝꿍에게 보여 주는 마무리.
- **산출물**: 묶음(계보 종점). 학급 공용 조직·별·친구 PR 은 v1 제외(확정).
- **본문**: 12~22강 산출물이 어디서 왔는지 «지도 한 장»으로 재작성.

## 1. 학생 화면 — 발견 3건 (증거 게이트 3/3 통과)

### f7 · severity 3 · 미션 1 은 명령 둘을 요구하는데 남은 하나를 안 알려준다
- 근거: `s7-shot`·`s7-text` / `lab-shell.ts:211` `ranCommands.includes('ls') && includes('pwd')`
- 증상: 「오, 드디어 뭔가 됐다! 근데 그 다음엔? 2번을 해야 하나?」
- `ls` 를 쳐도 왼쪽 「지금 할 일」이 **미션 1 문구 그대로** — 성공 표지가 없어 그 자리에서 멈춘다.
- 고침: 명령이 미션의 «일부»를 채우면 그 자리에서 남은 것을 말한다 —
  「ls 확인. 이제 pwd 도 쳐 보세요 — 둘 다 하면 2번으로 넘어갑니다」. 미션판에 진행 표시(1/2)도 같은 근거.

### f8 · severity 3 · 입력칸 placeholder 가 영원히 `ls`
- 근거: `s4-shot`·`s4-text`·`s7-shot` / `client/src/components/learn/LabTab.tsx:371` `placeholder="ls"`
- 증상: 「ls 를 쳐보세요라고 했는데, 내가 뭘 입력해야 하는지 몰라」
- `ls` 결과가 이미 나온 화면에서도 회색 `ls` 를 제안한다 — 방금 한 것을 또 하라고 말하는 셈.
- 고침: placeholder = **현재 미션이 요구하는 다음 명령**(미션 1 에서 ls 를 이미 쳤으면 `pwd`, 미션 2 면 `cat runs/run-1.txt`).

### f9 · severity 2 · `help` 사전이 화면을 채워 방금 친 명령의 결과를 밀어낸다
- 근거: `s6-text`·`s7-shot`
- 증상: 「명령어 뜻은 알겠는데, 실제로 뭘 해야 하는지는 여전히 모르겠어」
- 맨 위 안내가 「지금 할 일 → lab missions」라 **또 한 번 쳐야** 답이 나온다.
- 고침: `help` 출력 **맨 끝**에 「지금 할 일 — …」 한 줄을 붙인다. 🚨 사전 자체는 줄이지 말 것 —
  학생이 유일하게 «이해했다»고 말한 부분이다.

### 미션 2 에 파일 이름이 없다 (이번 run 미도달 — `inferred`)
`goal` = 「runs/ 안에 답이 셋 있습니다. cat 으로 셋 다 열어…」인데 판정은 `LAB_RUN_FILES`
(`runs/run-1.txt`·`run-2.txt`·`run-3.txt`) **셋 다** 열어야 통과다. 화면 어디에도 그 이름이 없다.
이번 캡처는 f7 때문에 미션 1 에서 멈춰 **여기까지 못 갔다** — 코드 근거만 있다. 어댑터를 미션 2 까지
늘려 한 번 더 밟아야 «directly-observed» 로 승격된다.

## 2. 교사 화면 — 발견 2건

### t1 · severity 3 · 진행 단위가 «문항»뿐이라 실습실 7미션이 안 보인다
- 근거: `s5-text`(「3조 민서 · 대기 · 0/7 문항」)·`s3-text`·`s5-shot`
- 90분이 흘러가는 곳은 **4번 문항 안의 미션 7단계**인데, 25명이 전부 미션 2 에 몰려도 교사 화면은
  「1/7 문항」으로 똑같다. **오늘 제보를 교사가 못 보는 이유가 이것이다.**
- 고침: 실습 문항에 한해 학생 줄 진행을 미션 단계로(「실습 2/7 — 세 결과 열어 보기」).
  데이터는 이미 클라이언트에 있다(`labMissionIndex`·`labEarnedIndex`).
- 🔑 수업 운영상 **값이 가장 큰 항목** — «몇 명이 어느 미션에 몰려 있는가»가 이 수업의 유일한 조종간이다.

### t2 · severity 3 · 학생이 들어온 뒤 교사가 누를 것이 없는데, 문구는 있다고 약속한다
- 근거: `s3-text`(「학생을 받은 뒤 수업을 시작하세요」) vs `s5` 버튼 셋(`s5-e2` 시연·`s5-e3` QR·`s5-e4` 종료)
- 증상: 「학생이 들어왔어요! 근데 수업을 어떻게 «시작»하지?」
- 고침: **없는 버튼을 만들지 말고, 없는 버튼을 약속한 문구를 고친다** — 「학생이 들어오면 각자
  진행합니다. 교사는 현황만 보면 됩니다」 + 학생 1명 이상일 때 «시연하기»를 1차 행동으로.

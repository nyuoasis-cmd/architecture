# A/B Eval Rubric — Architecture Academy

> SDD §14.4 통과 기준 정합

## 평가 항목 (각 응답마다 5점 척도)

### 1. 이해 용이성
**비전공자가 4문장 안에 개념을 파악할 수 있는가?**

| 점수 | 의미 |
|------|------|
| 5 | 한 번 읽고 즉시 이해. 핵심이 한 문장으로 떠오름 |
| 4 | 한 번 읽으면 대체로 이해. 작은 부분만 흐릿 |
| 3 | 두 번 읽어야 함. 일부 용어가 모호 |
| 2 | 두 번 읽어도 절반만 이해. 추상적 표현 많음 |
| 1 | 무슨 말인지 모르겠음. 전공자용 같음 |

### 2. 비유 자연스러움
**비유가 한국 일상에서 즉시 떠올리기 쉬운가?**

| 점수 | 의미 |
|------|------|
| 5 | 비유가 너무 자연스러워서 "아!" 소리 나옴 |
| 4 | 비유가 적절함. 약간만 부자연스러움 |
| 3 | 비유는 있지만 살짝 어색하거나 멀음 |
| 2 | 비유가 억지스럽거나 한국 정서와 안 맞음 |
| 1 | 비유 없음 또는 외국 사례라 와닿지 않음 |

### 3. 정답성 (운영자만 평가)
- **PASS**: 사실 관계 정확, 잘못된 정보 X
- **FAIL**: 사실 오류 있음 (예: TCP를 HTTP보다 위 계층이라고 설명)

## 통과 기준 (Haiku 확정 → Sonnet 미사용)

다음 5개 모두 충족 시 Haiku 4.5 기본 모델로 확정:

- [ ] **4문장 이하 준수율 ≥ 90%** (자동 측정, run-eval.mjs 출력)
- [ ] **이해 용이성 평균 ≥ 4.0** (Haiku 응답들의 평가 평균)
- [ ] **비유 자연스러움 평균 ≥ 4.0** (Haiku)
- [ ] **정답성 PASS율 ≥ 85%** (Haiku, 17/20 이상)
- [ ] **§11.7 후처리 차단율 < 5%** (별도 측정 — eval 단계에서는 후처리 미적용이므로 이 기준은 PR #5 통합 후 재측정)

1개 이상 미충족 시:
- Sonnet 기본 + Haiku fallback (비용 §5.4.7 표 참조 — 월 $200~$471 범위)

## 평가자 구성

- **운영자 1명** (정답성 + 이해 용이성 + 비유 자연스러움 모두)
- **비전공자 시범 사용자 2~3명** (이해 용이성 + 비유 자연스러움만)
  - 정답성은 비전공자가 판단 어려움 → 운영자만
- **블라인드 조건**:
  - 평가자에게 어느 응답이 Haiku/Sonnet인지 비공개 (results-*-blind.md만 전달)
  - 정답표(results-*-truth.md)는 평가 완료 후 공개

## 평균 계산 방법

각 평가자 점수를 산술 평균.

예: Haiku Q01 응답에 대해
- 운영자: 이해 4 / 비유 5
- 시범 사용자 1: 이해 5 / 비유 4
- 시범 사용자 2: 이해 4 / 비유 5
→ Q01 Haiku 이해 평균 = 4.33, 비유 평균 = 4.67

20문항 평균을 다시 산출 → 전체 통과 기준 ≥ 4.0과 비교

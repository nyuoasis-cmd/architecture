👀 학생 화면 미리 보기

실제 수업하는 화면. 여기선 교안이 안 보임

「👀 학생 화면 미리 보기」를 누르는 순간 교안이 시야에서 사라집니다. 교사는 수업 중에 뒤로가기 → 교안 확인 → 다시 앞으로를 반복하게 됩니다. DESIGN-POLICY §9.H-14 의 «학생 화면 ⊂ 교사 화면(상위집합)» 원칙과도 어긋납니다 — 지금은 교집합이 아니라 분리입니다.

C · 제안 (수정)

교안은 탭 하나 — 골격은 그대로

사이드바를 따로 두지 않습니다. 콘텐츠 탭 줄 맨 뒤에 📋 교안을 하나 더 붙이고, 교사에게만 보이게 합니다. 학생 탭 5개 ⊂ 교사 탭 6개 — §9.H-14 «학생 화면 ⊂ 교사 화면»이 문자 그대로 성립합니다.

이 안이 나은 이유 세 가지
§9.D-5 폭 정책사이드바가 없으니 폭이 안 늘어납니다. 앞서 그린 1440+300 안은 «1400px 이상 금지»에 정면으로 걸렸습니다
§9.H-14 상위집합학생 탭 5 ⊂ 교사 탭 6. 레이아웃이 갈라지지 않고 탭 하나만 더 있는 같은 화면
동일 포맷 원칙골격을 안 건드립니다. 교안용 300px 변형 컴포넌트를 새로 만들 필요가 없습니다
맞바꾸는 것 하나 — 교안과 학생 콘텐츠를 동시에 볼 수 없습니다(탭이라 하나씩). 사이드바 안은 동시에 보였고요. 실제 수업에서 교사는 «지금 뭘 시킬지»를 확인한 뒤 학생 화면으로 돌아가는 패턴이라 탭 전환으로 충분하다고 봤습니다 — 동시 표시가 꼭 필요하면 말씀해주세요(그때는 폭 정책 예외를 먼저 받아야 합니다).
🚨 별건으로 발견한 폭 드리프트 — 학생 학습 화면은 지금도 max-w-[1440px] 입니다(승인 목업 student-learn.html 도 1440). §9.D-5 는 «페이지 표준 1184px · 1400px 이상 금지»라 이미 어긋나 있습니다. 이번 건과 별개이며, 3컬럼 복원 PR 에서 1184px 로 맞출지 예외를 받을지 정해야 합니다.

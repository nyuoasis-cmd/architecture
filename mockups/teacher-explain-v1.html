이 Q&A 수업 목표
학생이 컴퓨터의 다섯 가지 큰 부품—입력·처리·저장·출력·연결—이 따로따로가 아니라 한 팀으로 일한다는 점을 받아들이게 합니다.
교사가 먼저 해줄 말
"컴퓨터 안에 작은 회사가 있다고 생각해봐. 비서가 이메일을 받고, 직원이 처리하고, 캐비닛에 보관하고, 우편으로 보내고, 외부 기관과 연락해."
개념 설명
컴퓨터는 한 덩어리가 아니라 다섯 종류의 부품이 협력하는 구조예요. 입력 장치(키보드·마우스), 처리 장치(CPUCPU · Central Processing Unit컴퓨터의 두뇌 — 명령어를 해석하고 계산을 수행하는 부품), 저장 장치(RAM·SSD), 출력 장치(화면·스피커), 연결 장치(와이파이·랜선)가 각자 맡은 일을 하고, 이 중 하나만 빠져도 작업이 멈춥니다.
풀어쓴 설명

컴퓨터 부품들은 도로(버스)로 이어진 작은 도시 같아요. 데이터(시민)가 빠른 동네(캐시), 보통 동네(메모리), 시 외곽(디스크)을 오갑니다. 가까운 동네일수록 빠르지만 좁고, 먼 동네일수록 넓지만 한참 걸려요.

실생활 활용 연결
교무실 일과와 닮았어요. 학부모 전화(입력) → 담당 교사 처리(CPU) → 문서함 보관(저장) → 회신(출력) → 외부 기관 연락(연결). 컴퓨터 부품도 똑같이 '받고-처리하고-보관하고-내보내고-연결한다'는 다섯 단계를 갖고 있다고 설명하면 학생이 빨리 이해합니다.
학생에게 던질 질문
  • Q. 메모리(RAM)와 SSD가 둘 다 저장 장치인데 왜 따로 둘까요?
    A. RAM은 책상 위 작업 공간이고 SSD는 책장이라고 비유합니다. 책상은 빨리 꺼내 쓸 수 있지만 좁고 전원이 꺼지면 비워지고, 책장은 느리지만 영구 보관합니다.
  • Q. 와이파이는 어느 부품에 들어가나요?
    A. 연결 장치에 속합니다. 컴퓨터 안의 우편함이라고 부르면 외부와 대화하는 창구라는 점을 학생이 떠올립니다.
  • Q. CPU와 GPU는 무엇이 다른가요?
    A. CPU는 다양한 일을 순서대로 빠르게, GPU는 단순한 계산을 동시에 수만 개 처리합니다. 만능 사무원과 단순 작업 군인의 비교로 설명하면 직관적입니다.
⚠️ 흔한 오개념 + 정정법
"CPU가 좋으면 컴퓨터가 빨라진다" 라고 단정하는 학생이 많습니다. 메모리(RAM)가 부족하면 CPU가 아무리 좋아도 디스크를 자주 읽느라 느려집니다. 다섯 부품의 균형이 속도를 결정한다고 정정해 주세요. 7장 병목 비유로 자연스럽게 이어집니다.
시연 시작 전 체크
시연은 네 시나리오(타이핑→화면 / 파일 저장→읽기 / 인터넷 요청 / 영상 재생) 순서로 진행해주세요. 각 시나리오에서 학생에게 "지금 어느 부품이 일하고 있을까?" 손가락으로 가리키게 하면 5대 부품을 자연스럽게 외웁니다.
교사 메모
"그럼 부품이 여러 개면 컴퓨터가 더 빨라져요?" 라는 질문이 자주 나옵니다. "많기만 한 게 아니라 균형이 맞아야 빨라요" 라고 답하고, 7장 병목 비유를 미리 예고하면 학습 흐름이 자연스럽습니다.

컴퓨터는 한 덩어리가 아니라 다섯 종류의 부품이 협력하는 구조예요. 입력 장치(키보드·마우스), 처리 장치(CPU¹), 저장 장치(RAM²·SSD³), 출력 장치, 연결 장치가 각자 맡은 일을 하고 이 중 하나만 빠져도 작업이 멈춥니다.

² RAM · 책상 위 작업 공간 — 빠르지만 휘발
³ SSD · 책장 — 느리지만 영구 보관

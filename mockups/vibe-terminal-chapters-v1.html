무엇을 시킬 것인가

Claude · Codex(gpt-5.5) · GLM 5.2 세 모델을 다른 렌즈로 발산시키고 서로 비평시킨 결과입니다. 아래는 6개 강의 실습 구현안과, 그 밑에 깔릴 플랫폼 골격, 그리고 모델끼리 갈린 지점입니다. 갈린 지점이 결정하실 자리입니다.

먼저회의가 뒤집은 것 세 가지

제가 앞서 드린 안에서 세 개가 반박당해 바뀌었습니다. 이게 이번 브레인스토밍의 실질 소득입니다.

1) claude CLI는 브라우저에서 안 돕니다

Codex 공식 CLI는 브라우저를 지원 환경으로 두지 않습니다. WebContainer 안에서 claude 를 그대로 돌린다는 제 전제가 틀렸습니다. → 수업 전용 claude 셸을 우리가 만든다(지원 명령을 명시하고, 실물과 다르다는 것을 학생에게 공개).

2) 명령 로그로 채점하면 안 됩니다

CodexGLM 둘 다 반대. 클라이언트 이벤트는 위조 가능하고, 짝의 내비게이터는 로그가 없고, 루브릭을 공개하는 순간 git log 남발이 최적 전략이 됩니다. → 채점은 서버 재검증, 로그는 관제용 신호로 강등.

3) 하드 릴레이는 6주에 안 맞습니다

GLM 3주 전 AC가 오늘을 막는 구조는 12~15주 과목의 것입니다. 결석 1회가 성적 하락으로 구조화됩니다. → 체크포인트 격자로 완화(맥락은 잇되 의존은 끊는다).

골격모든 강이 공유하는 판

강별 설계 전에, 여섯 강이 똑같이 올라탈 바닥을 먼저 정합니다. 이게 흔들리면 강 설계는 의미가 없습니다.

4) AI 예산 3중 — 이 수업에서 유일하게 돈이 드는 곳

학생 입력 3회 / 미션

「AI에게 보내기」를 미션당 3번. 교사가 1회 추가 지급 가능. 이 숫자가 곧 교육 설계입니다 — 16강은 3회 안에 승인받는 것이 과제 그 자체입니다.

모델 왕복 8회 / 입력

도구 호출 루프가 안에서 8번 돌면 학생은 1회로 알지만 요금은 8배입니다. 서버가 원자적으로 끊습니다.

토큰 상한 + 순번 큐

30명이 동시에 시작하면 429가 납니다. 재시도 대신 순번을 화면에 보여줍니다.

5) 골든 스냅샷 — npm install 을 아예 안 시킨다

Codex 30명이 동시에 설치하면 학교망·레지스트리·브라우저 메모리가 같이 터집니다. 게다가 WebContainer는 네이티브 애드온을 못 돌립니다. 그래서 순수 JS + Node 내장 node:test 로만 미션을 구성하고, 버전 고정된 폴더를 통째로 마운트합니다. GLM 그리고 이 고정 스냅샷을 안전장치가 아니라 교재로 씁니다 — 12강에서 「내 것 3회」와 「고정본 3회」를 나란히 diff 하는 것이 수업의 핵심 장면이 됩니다.

~/attend $ lab lesson secrets
   ⚠ 오해 주의 — CLAUDE.md 에 «비밀값을 커밋하지 마»라고 적는 것은
     보안 장치가 아닙니다. 그건 AI에게 주는 «부탁»이지 «벽»이 아닙니다.

이견모델끼리 갈린 지점 — 여기가 결정하실 자리

이견 1 · 게임화를 어디까지 넣을 것인가

GLM 「git 탐정: 저장소 살인사건」, 「PR 법정」, 「주식회사 30인」 같은 서사 구조를 강하게 밀었습니다. Codex는 «역할극 설정이 터미널 초심자에겐 오버헤드», «재판 절차가 시간을 먹어 90분 회전이 준다»고 반대했습니다.
제 판단: 서사는 강당 하나만. 위 안에서는 16강(하청업체)과 22강 후반(PR 법정)에만 넣고 나머지는 담백하게 뒀습니다. 첫 학기에는 이 정도가 안전합니다.

이견 2 · 산출물을 얼마나 강하게 이을 것인가

Claude 6강 하드 릴레이(3주 전 AC가 오늘을 막는다). GLM 정면 반박 — «초보자의 정상적 학습곡선에 대한 처벌», «결석 1회가 성적 하락으로 구조화». Codex는 유지하되 요구사항 ID로 추적하자는 절충.
제 판단: GLM이 맞습니다. 체크포인트 격자 + 얇은 공통 맥락으로 갑니다. 다음 강은 이전 산출물이 없어도 시작되고, 있으면 더 좋습니다.

이견 3 · 만들 것인가 살 것인가 미해결

GLM이 제기한 가장 아픈 질문입니다 — 입장 게이트 + 원격 비상석 + 격리 실행기 + git 래퍼 + PR 화면 + 예산 서버 + 텔레메트리 + 수업용 claude 셸을 다 만들면 수개월치 플랫폼 작업입니다. 6주·30명 강좌에 이걸 자체 구축하는 게 맞는가? GitHub Codespaces·Classroom 대비 비교가 아직 없습니다.
제 판단: 이건 제가 정할 게 아닙니다. 다만 MVP 컷은 있습니다 — 아래.

마지막주무시고 나서 정해주실 것 넷

1. 수업용 claude 셸을 만드는 것에 동의하시는지
실물 CLI는 브라우저에서 안 돕니다. 우리가 만든 셸은 지원 명령이 한정되고 동작도 실물과 다릅니다. 학생에게 「이건 수업용이고 실물은 이렇게 다르다」를 명시하고 갈 것인지, 아니면 이 제약 때문에 다른 실행 환경(Codespaces 등)을 볼 것인지.
2. 만들 것인가 살 것인가
자체 구축(수개월) vs GitHub Codespaces·Classroom 조합. 제 추천은 「12강 MVP만 자체 구축해서 한 반 돌려보고 결정」 — 지금 비교만 하면 탁상공론이 됩니다.
3. AI 월 지출 상한을 얼마로 둘 것인지
이 실습을 켜기 전에 반드시 붙여야 합니다. 「내 차례」 라우트에는 지금 돈 천장이 없습니다. 30명 × 미션 3회 × 6주 기준 추산을 붙여 드릴 수 있습니다.

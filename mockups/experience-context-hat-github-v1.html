jery 요청 5 — 「3강 체험도 그렇고 체험 탭이 전부 맥락이 없어 학생도 교사도 이해하기 어렵다」
지금 화면의 실제 상태: 3강(github형)에는 이미 두 가지가 있다 — 「📖 아까 읽은 비유」(단계 다리)와 「🧭 지금 하는 일」(도슨트 자막). 그런데 둘 다 «지금»만 말한다. 왜 이걸 하나(배포를 왜 배우나)와 언제 쓰나(이걸 실제로 만나는 장면)는 없다. 그래서 학생은 버튼을 순서대로 누르지만 «무엇을 배운 건지»를 못 집는다.
제안 = 「🧭 체험 머리표」 하나를 부품 3종에 공통으로 붙인다. 세 질문에 늘 답이 떠 있고, 스크롤로 사라지지 않는다.
1) 왜 하나 — 이 체험이 붙잡아 주는 개념 한 개 + 생활 비유  ·  2) 언제 쓰나 — 학생이 실제로 만날 장면  ·  3) 지금 할 일 — 다음 한 걸음 하나 + 진행 N/M

왜 하나
내 컴퓨터에 있는 것은 나만 본다. 남이 보게 하려면 «누구나 닿는 곳»에 올려 두고 주소를 줘야 한다 — 그게 배포다. 오늘은 그 스위치를 한 번 켠다.
언제 쓰나
여러분이 누른 모든 링크가 누군가의 배포 결과다. 학교 홈페이지, 포트폴리오, 동아리 소개 페이지 — 만들었는데 주소가 없으면 «완성»이 아니라 «서랍 속»이다.

무엇이 달라지나

지금

  • 「📖 아까 읽은 비유」 + 「🧭 지금 하는 일」 둘 다 «지금»만 말한다
  • 왜 배포를 배우는지가 읽기 탭에만 있고, 체험으로 넘어오면 끊긴다
  • 학생은 초록 버튼을 순서대로 누르고 끝난다 — «무엇을 배웠나»가 안 남는다
  • 교사도 이 화면만 보고는 «이 체험의 목표»를 한 문장으로 말하기 어렵다

제안

  • 머리표가 왜/언제 두 칸을 더한다 — 비유 다리와 도슨트는 그대로 둔다(잘 되고 있다)
  • 「언제 쓰나」가 학생 생활로 착지한다 — «네가 누른 모든 링크»
  • 단계 N/M — 대본이 몇 걸음인지 처음부터 보인다
  • 교사가 머리표 두 칸을 그대로 읽으면 도입 설명이 된다

S4-B · 확정 (2026-08-11)

교안에서 «시간»을 뺀다 — 하네스만이 아니라 전부

시간 분배는 교사가 자기 반을 보고 하는 일입니다. 교안이 분 단위로 짜 놓으면 교사가 그걸 따라야 할 규격으로 오해하고, 실제로는 반마다 어긋나서 「계획한 45분을 지났어요」 같은 틀린 잔소리만 남습니다.

남는 것

칸의 순서 · 학생이 하는 일 · 교사가 던질 발문 · 그 칸이 다루는 문항 · 함정 · 마무리 한 마디. 교안의 값어치는 원래 여기 있었고, 분은 거기 얹힌 장식이었습니다.

대신 잃는 것 하나 — 「지금 이 칸」 자동 하이라이트가 사라집니다(경과 분에서 파생했으므로). 제안: 교사가 칸을 눌러 «여기 하는 중»을 직접 켠다. 시간을 재지 않으면서 «어디까지 왔나»는 유지됩니다. (S3 화면에 반영)
🚨 이건 하네스 PR 이 아니라 별건입니다 — 기존 17개 교안을 전부 건드리므로, 하네스 6강을 만들기 전에 독립 PR 로 먼저 빼는 게 맞습니다. 안 그러면 하네스 PR 리뷰에 교안 17개 diff 가 섞입니다.

S6 · PR 순서

교안은 여전히 별도 PR

PR n−1

PR n

PR n+2
교안 6개 ← 이 목업. 문항이 실존해야 계약 ⑨를 통과하므로 반드시 뒤
